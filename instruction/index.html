Системные требования

Минимальные системные требования для установки и эксплуатации ПО следующие:

Оперативная память: не менее 1 Гб.

Операционная система: Windows, Linux, MacOS.

Скорость локальной сети: не менее 10 Мбит/сек.

Скорость интернет-соединения: не менее 5 Мбит/сек.

Процесс установки ПО

1. Пользователь должен перейти на сайт по ссылке: https://orm.orm-expert.ru.

2. Далее ему необходимо нажать на кнопку “Войти”.

3. ПО осуществит переход пользователя на страницу авторизации, на которой потребуется в соответствующих полях указать логин и пароль, предоставленный после заключения договора.

4. После этого ПО произведет вход в учетную запись пользователя.

Процесс завершения работы ПО

1. Для завершения работы ПО пользователю необходимо в верхнем правом углу нажать на кнопку “Выйти”.

2. Далее необходимо закрыть соответствующую вкладку в браузере.
